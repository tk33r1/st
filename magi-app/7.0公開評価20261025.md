# MAGI 7.0 公開評価

2026-10-25（JST）。ワイヤレス接続したAndroid実機で確認後にコミットし、Worker・Web/PWA・署名済みAPKを7.0として公開した。

## 変更と対象

- 公開済み6.9と、その後のmain（`684a3e40`）の処理整理を維持し、[一時チャットUI改修](一時チャットUI改修記録20261025.md)を統合した。画面・Workerの元の設計書と6.9公開評価は当時の記録として残す。
- 中央の一時案内、詳細モーダル、点線吹き出し＋からの通常復帰を追加。一時のパーソナライズを会話内だけで選択し、通常の設定はアプリ管理にトグル・呼び方・指示をまとめる。
- 新しい一時の選択はWorkerの機能通知とsessionを照合する。旧画面の一時要求は引き続き設定を適用しない。会話・評価・音声の非保存経路、既存の利用制限カウンターを維持する。D1スキーマ変更なし。
- 表示7.0、npm 7.0.0、Android versionName 7.0 / versionCode 700。PWAはapp.js?v=20261025_11、magi-shell-v121。

## 検証

- 最新main統合後の全Node回帰398件がPASS。ログは`workers/.wrangler/release-7.0/regression.log`。トップ/PWAとAndroid模擬ブラウザ、明暗テーマ・320px等の確認済み範囲はUI改修記録を参照する。
- ワイヤレスADBでSamsung SM-S931Qへ接続。本番アプリのデータを使わない別ID`st.tk.magi.b3probe`をインストールし、実機上のタップと文字入力でアプリ管理のトグル・保存を確認した。入力文字列は合成値だけを使用した。
- 実機で中央の案内、＋アイコン、詳細モーダルとAndroidの戻る、ラジオ選択と完了、会話開始後の再選択を確認した。通常の設定がオフでも一時に明示適用でき、なしへ戻せる。各要求のモードと設定、通常文脈の混入がないことも検査した。
- 合成画像・本文を一時送信し、設定の切替前後で`files/magi/`配下の全ファイルhashが一致した。通常の設定値も変わらず、評価・共有は非表示。Java受信入口の一時要求拒否も確認した。
- 実際のホーム移動で機能確認中の通信を中止し、復帰だけでは送信しないこと、点線吹き出し＋のタップで通常の履歴・下書き・共有資料に戻ることを確認した。一時パーソナライズを選んだ状態でforce-stopして再起動し、一時会話・選択が復活しないこと、通常履歴と設定が保たれることを確認した。
- 実機は固定SSEを返す検証用通信で確認した。実AI・実Fish Audioへの送信は0。記録・画像は`workers/.wrangler/release-7.0/device/`に保持する。
- 署名済みAPKの全wwwファイルが作業ツリーと一致し、版・v1/v2署名・公開6.9と同じ証明書であることを確認した。公開元コミット`0d89c776f5d98b2fa686b26b497184d8ed667f11`との照合もPASS。
- APK SHA-256: `33579ceb1cba34597d0fd8d0a7c89c64de3b4f5cedbe840b84c5025b95cad06b`。
- 署名証明書SHA-256: `0ab1a655a53a2b39d325167508a9b37d2ded1e9d1e6ae4a00431d28b54a41df9`。

## 制限

- 実機の応答は合成値であり、実モデルの呼び方・指示の遵守、実音声生成・再生を確認したものではない。iOS実機、他のAndroid版・機種も未確認。
- UI改修記録のとおり、旧来のブラウザ検証2本は変更前でも同じ箇所で失敗する。今回の合格件数に含めず、関連する新UI・非保存・戻る操作は専用の検証と実機で確認した。
