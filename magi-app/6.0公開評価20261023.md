# MAGI 6.0 公開評価（回答の操作列・共有・ソース）

実装済み（2026-10-23）。正本はコード。本人の「公開まで進める」「6.0」により、読み上げ設計の公開 C1 を 6.0 / 60 として一般公開した。検証の詳細は [読み上げ評価](../workers/magi2/読み上げ評価.md)。

- 統合人格の回答の下を［コピー］［🔊］［共有］［いいね］［︙］と、出典があるときだけ右寄せの［ソース］にした（トップページとアプリ）。絵文字のリアクションは［︙］から選び、選んだ絵文字は［︙］の右に出る。人格のカードの操作列は今のまま。
- 共有: 回答の本文と出典を、Android は公式の Share プラグイン、Web は `navigator.share` で渡す。共有できない環境ではコピーする。会話の URL は付けない。
- ソース: Web で確かめた回答の出典を［ソース］から開く一覧（トップページは操作列の下、アプリは下からのシート）に移した。アイコンは Worker が出典の本文を読むときに取った data: URL だけで、画面から出典のサイトへ取りに行かない。
- 読み上げ: Worker の署名と画面の再生を入れたが、`SPEECH_ENABLED="false"` のため 🔊 は出ない（C1b で有効にする）。
- Android のネイティブ受信が `speech` イベントを保存するようにした。
