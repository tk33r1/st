# 情報画面のCSS衝突修正・実機検証

実装済み（2026-10-24）。正本はコード。6.76で公開。

## 原因と修正

6.75で情報画面へ付けた`agent-page`が、既存のサイト案内リンク用CSSと衝突した。リンク用の緑枠・文字色・10pxのpaddingがパネルにも適用され、Androidの安全領域を含むpaddingが失われた。以前の検査は中央配置と戻る階層を主に見ており、色・枠・実端末の安全領域の確認が不足していた。

- 情報画面のクラス名を`agent-info-page`へ変更。既存のサイト案内リンク用`agent-page`は保持。
- FAQ等の本文は通常の`--text-color`を明示。枠・角丸は追加しない。
- `agent-panel`の既存の安全領域と12pxを加えたpaddingが適用される状態を復元。
- 回帰の画面検査へ、左右の枠0・角丸0・本文色・安全領域を含むpaddingの確認を追加。

## ワイヤレスデバッグによる確認

Samsung SM-S931Qに入っている本番6.75で、緑枠・緑本文・ステータスバーとの重なりを実際に確認した。

修正版は本番とは別IDの`st.tk.magi.infolayout`で一時的に確認。実際のCapacitorとSystemBarsを使い、端末の安全領域を取得した。検証版だけ送信操作を拒否し、AIへの送信、会話削除、本番アプリの入れ替えはしていない。

- WebViewは360×780 CSS px、表示倍率3。実端末の上の安全領域は34px。
- 戻るボタンの上端は46px。安全領域34pxの下に12pxの間隔があり、見出しもステータスバーより下に収まる。
- MAGIについて・FAQ・利用規約・プライバシーポリシー・バージョン情報・更新履歴・アプリ管理を、ダーク／ライトの計14画面で測定・撮影。
- 全画面の左右の枠0、角丸0。本文はダークがrgb(212,212,212)、ライトがrgb(31,41,55)。アプリ管理の補助文は従来のsecondary色を維持した。
- 実端末のAndroid戻るで、詳細→MAGIについて、更新履歴→バージョン情報、一覧・アプリ管理→会話画面を確認。画面例外0。
- 検証APKのapp.jsは作業ファイルとバイト一致。index.htmlも検証用の送信拒否スクリプトを除いて一致。

Web・PWA・模擬Androidの画面検査とNode回帰362件も成功。スクリーンショット・測定値・検証APKはignoredの`workers/.wrangler/magi-info-layout-device/`に保持する。検証後に別IDアプリと今回のADB転送を削除し、本番のMAGIと会話データは保持した。
