PDF Studio について

PDF Studio は、PDFの回転・結合・分割・並べ替えを1つの画面でまとめて行える無料のPDF編集ツールです。一般的なオンラインPDFツールと違い、ファイルをサーバーにアップロードしません。処理はすべてブラウザ内のJavaScriptで完結するため、契約書・請求書・社内資料のような外部に出したくないPDFでも安心して扱えます。オフラインでも動作します。

1画面で完結する編集

多くのオンラインツールは「回転」「結合」「分割」がそれぞれ別ページに分かれており、回転したあとに分割したい場合は一度ダウンロードして再アップロードする必要があります。PDF Studio はサムネイル一覧の上で回転・削除・並べ替え・他PDFの挿入をすべて行い、最後に1度だけ書き出します。アップロードの往復が不要なので、ページ数が多いPDFほど速く終わります。

片面スキャンの奇数偶数交互結合

両面原稿を片面スキャナで取り込むと、「奇数ページだけのPDF」と「偶数ページだけのPDF」の2ファイルに分かれてしまいます。交互結合を使うと、この2つを1・2・3・4…と正しい順序に組み直せます。裏面を逆順に読み取ってしまった場合のために、偶数ページ側を逆順にするオプションも用意しています。

2in1・中綴じ小冊子の面付け

2ページ分を1枚に並べる2in1（N-up）と、印刷して二つ折りにするだけで冊子になる中綴じ面付けに対応しています。中綴じでは総ページ数を自動的に4の倍数に調整し、白紙を補います。左綴じ（横書き）と右綴じ（縦書き・和書）を切り替えられます。面付けはページを画像化せずベクターのまま配置するため、文字は鮮明なまま、テキスト検索もそのまま使えます。

本当に消える墨消し（黒塗り）

PDFに黒い四角形を描くだけの「黒塗り」は、下にある文字がPDFの中に残ったままです。テキストをコピーしたり検索したりすれば、隠したはずの内容が読めてしまいます。PDF Studio の墨消しは、指定した領域を塗りつぶしたうえでそのページを画像として描き直すため、元のテキストデータがPDFから消えます。復元はできません。

ローカル完結のPDF圧縮

PDFの圧縮はサーバー側の処理に頼るサービスがほとんどですが、PDF Studio は解像度（DPI）と画質を指定してブラウザ内で再構成します。写真やスキャン画像が中心のPDFで特に効果があります。圧縮したPDFはページが画像になるため、テキストの選択・検索はできなくなります。文字の鮮明さを保ちたい場合は圧縮なしで書き出してください。

PDFを画像に変換する（AVIF・可逆WebP対応）

編集した状態のまま、ページごとに画像へ書き出せます。PNG・JPEG・WebPに加えて、次世代フォーマットのAVIFと可逆（ロスレス）WebPにも対応しています。AVIFはPNGと比べて大幅に軽く、可逆WebPは画質を一切落とさずにPNGより小さくできるため、資料をWebサイトに載せる用途に向いています。解像度は1倍から4倍まで選べ、複数ページはZIPでまとめてダウンロードされます。

AVIFと可逆WebPはブラウザ標準の機能では出力できないため、初回だけエンコーダ（WebAssembly）を読み込みます。読み込み後はオフラインでも変換できます。この変換もサーバーを使わず、端末の中だけで完結します。

URLからPDFを読み込む

手元にファイルがなくても、PDFのURLを貼り付ければ直接読み込めます。取得先がCORSを許可していない場合は、外部プロキシ経由での再試行を確認したうえで行います（プロキシを使う場合のみ、その運営者にURLとPDFの内容が渡ります）。

対応している操作

  • ページの回転（90°単位）・削除・ドラッグでの並べ替え
  • 複数PDFの結合、URLからのPDF読み込み
  • 分割（1ページずつ / N枚ずつ / 選択したページのみ）、ZIP一括ダウンロード
  • 奇数ページ・偶数ページの交互結合（裏面の逆順に対応）
  • 2in1・中綴じ小冊子の面付け（左綴じ / 右綴じ）
  • 墨消し（領域指定・実削除）
  • PDF圧縮（DPI・画質指定）
  • PNG / JPEG / WebP / 可逆WebP / AVIF への画像変換
  • 作成者名などメタデータの削除

ご利用上の注意

  • 閲覧パスワードが設定されたPDFは読み込めません。事前にパスワードを解除してください。
  • すべての処理を端末のメモリ上で行うため、非常に大きなPDF（数百MB規模）や数千ページのPDFはスマートフォンでは処理しきれない場合があります。
  • 入力フォーム・注釈・電子署名は、圧縮や墨消しを適用したページでは失われます。
