最適化の仕組み

        
      


      
このツールは、ブラウザの処理能力だけでファイルを最適化します。ファイルが外部サーバーに送信されることはありません。


      

        
 PNG / JPEG の変換

        
画像を渡すと輪郭を解析してベクターデータ（SVG）に変換します。この処理には imagetracerjs を使用し、変換後さらに SVG として圧縮します。

      


      
    
        
  • Illustrator や Sketch が残す不要なメタデータを削除します
    • 
        
  • 非表示の要素や空の属性を安全に削除します
    • 
        
  • パスデータやカラーコードの記述を最小化します（SVGO）
    • 
      


      

        
 aggressive について

        
小数点以下の精度を極限まで削り、viewBox などを強制削除してさらに軽くします。ただし複雑な図形では表示が崩れることがあります。

      


      

        
 Data URI について

        
CSS の background-image や img src にそのまま貼れる形式（data:image/svg+xml,...）でコピーします。Base64 より軽い URL エンコード形式です。
