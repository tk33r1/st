Tap BPM について

Tap BPM は、曲に合わせて画面を叩くだけでテンポ（BPM）を測れる無料のタップテンポツールです。測定と同時に、ディレイタイム、フレーム換算、DJ用のピッチ範囲まで自動で計算します。インストール不要・登録不要、すべてブラウザ内で完結します。

単純平均ではなく、最小二乗法で推定しています

多くのタップBPMツールは「直近数回の間隔を平均する」だけの実装で、1打ずれただけで数字が大きく揺れます。Tap BPM は各タップに拍番号を割り当て、時刻と拍番号を最小二乗法で直線近似してテンポを求めます。平均と違い、タップを重ねるほど推定が安定し、誤差が縮み続けるのが特長です。

結果には ±の推定誤差 と、あなたのタップ自体のブレ（ミリ秒）を併記しています。その数字を信用してよいかどうかを、数字自身が語る状態にするためです。

叩き間違い・拍抜けを自動で補正します

明らかにずれた1打は外れ値として計算から除外されます。また、1拍叩き忘れて間隔が2倍になった場合も、そこを「2拍分」と解釈して拍番号を進めるため、テンポが半分に崩れることがありません。何を補正したかは「計測の内訳」で確認できます。

タップの時刻には、イベントが実際に発生した時刻（event.timeStamp）を使っています。JavaScript の処理待ちによる数ミリ秒の遅れが測定値に混ざらないようにするためです。

ディレイタイムを手計算しなくて済みます

全音符から32分音符まで、通常・付点・3連符それぞれのミリ秒を一覧で表示します。ディレイやリバーブのプリディレイをテンポに同期させたいとき、表の数値をクリックすればその値だけをコピーできます。付点8分ディレイのような定番の設定も、電卓なしで一発です。

BPM欄に直接数字を入力すれば、タップせずにBPMからディレイタイムを求める計算機としても使えます。拍子を切り替えると1小節の長さもそれに追従します（6/8 や 7/8 にも対応）。

映像編集・DJ向けの換算

24 / 25 / 29.97 / 30 / 50 / 60fps それぞれについて、1拍が何フレームにあたるかを表示します。カット点を拍に合わせたいときに使えます。DJ向けには、ピッチフェーダーの可動域（±4% / ±6% / ±8% / ±16%）で到達できるBPMの範囲と、ハーフタイム・ダブルタイムのBPMを併記しています。

キーボード操作

  • Space … タップ
  • Backspace … 直前の1打を取り消す
  • Esc … 計測をリセット

しばらく叩かずにいると計測は自動的に区切られ、次のタップから新しい計測が始まります。区切りまでの残り時間はタップパッド下端のバーで見えるようになっています。区切られても表示中のBPMは消えないので、測ったあとに落ち着いて数値を写せます。

ご利用上の注意

  • タップの記録やBPMがサーバーに送信されることはありません。すべて端末内で処理されます。
  • ブラウザやOSの都合で、タップの時刻には数ミリ秒程度の揺らぎが残ります。8回以上叩けば影響はほぼ無視できます。
  • 楽曲によっては、あなたが「1拍」と感じた位置が譜面上の1拍と半分ずれていることがあります。その場合は ×2 / ÷2 で補正してください。
