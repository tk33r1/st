About & privacy

よくある質問

サービスの内容、料金、安全性、利用環境について、よくある疑問に回答します。

SAFE TOOLS とは何ですか？

CSV・PDF・画像・動画・テキスト・QRコードなどの変換、編集、生成をブラウザ上で行える Web ツール集です。専用ソフトをインストールせずに使え、ファイルや入力内容を外部へ送らないことを共通方針にしています。

無料で使えますか？会員登録は必要ですか？

すべて無料で、会員登録やログインも必要ありません。機能を使うためのアプリのインストールも不要です。任意の寄付は、ツールの利用可否や機能に影響しません。

SAFE TOOLS は安全に使えますか？

SAFE TOOLS は、入力したファイルや文字列を外部へ送らず、変換・編集・生成などの処理を利用者のブラウザ内で完結させる設計です。機密性の高いデータを扱う場合は、信頼できる端末と最新のブラウザを利用してください。

なぜファイルや入力内容が外部へ送られないのですか？

各ツールはファイルや入力内容を送信する処理を持たず、ブラウザ内の JavaScript で処理します。さらに Content-Security-Policy（CSP）により、ページが読み込みや送信に使える通信先を、このサイトとアクセス解析に必要な送信先だけに制限しています。この二段構えはページ先頭の CSP 設定から確認できます。

アクセス解析でファイルや入力内容が送信されますか？

いいえ。Google アナリティクスと Cloudflare Web Analytics はサイトの利用状況を把握するために使用していますが、ツールにはファイルや入力内容をアクセス解析へ渡す処理がありません。

広告は表示されますか？

いいえ。SAFE TOOLS には広告を掲載しておらず、広告配信のためのコードも組み込んでいません。サイトの改善に使うアクセス解析はありますが、広告コンバージョンは無効にしています。

外部のライブラリやフォントを読み込みますか？

ツールの処理に使うライブラリとフォントは tk.st 内に同梱し、外部 CDN から読み込みません。外部との通信はアクセス解析に必要なものに限り、寄付の窓口である Ko-fi はページ内容を読めない別の埋め込み枠としてのみ許可しています。

スマートフォンやタブレットでも使えますか？

多くのツールはスマートフォンやタブレットにも対応しています。ただし、大きなファイルや動画など負荷の高い処理は、端末の性能や空きメモリの影響を受けるため、パソコンでの利用をおすすめします。

大きなファイルも処理できますか？

処理できるサイズは、使用する端末のメモリやブラウザ、ツールの種類によって異なります。処理はサーバーではなく端末内で行うため、ファイルが大きいと時間がかかったり、メモリ不足で完了できなかったりする場合があります。

処理したファイルはサーバーに保存されますか？

いいえ。処理対象と処理結果を tk.st のサーバーへ保存する機能はありません。書き出したファイルは、利用者が指定した端末上の保存先にダウンロードされます。
