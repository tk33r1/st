# MAGI 4.6（公開2）の実機確認

確認中（2026-10-12）。[公開2の本番記録](先行改修公開2評価.md) に続く本人からの確認結果。公開時の記録は書き換えず、実機の結果をここに追加する。

| 項目 | 状態 | 本人の確認 |
| --- | --- | --- |
| 会話履歴の引き継ぎ | 確認済み | 「会話履歴」であることを説明し、本人から「それなら問題ありません」 |
| 通常アイコン | 確認済み | 「アイコンは変わりました」 |
| 起動時の端末テーマ反映 | 確認済み | Androidのダークテーマをオフにしてアプリを完全終了・再起動する確認を依頼し、「白い背景になりました」 |
| 起動中の設定変更への追従・手動切替後の非追従 | 未確認 | 起動時の確認とは分ける |
| Android 13以降の単色アイコン | 未確認 | 通常アイコンの確認とは分ける |
| 通常相談・MAGI・画像付き各1回 | 未確認 | 本番Chromiumの確認とは分ける |
| System & Privacy・機内モード | 未確認 | 本番Chromiumの確認とは分ける |
| 更新通知・ダウンロード・閉じた版・24時間抑止 | 未確認 | 本人の「アップロード履歴はまだ表示されていません」が更新通知を指すかは未確定。通常の4.6は同じ4.6の通知を出さない。非公開の通知確認用APKによる実機検証はまだ行っていない |
| 本人以外の4.4利用者への案内・入れ直し | 未確認 | 本人以外への連絡は行っていない |

上記3項目の確認を、実機検証全体の合格とは扱わない。残る筋書きは`magi2先行改修検証計画.md` §4.3と本番記録を参照。公開1のモデル変更はまだ公開していない。
