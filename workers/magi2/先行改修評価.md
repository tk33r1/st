## 本番Worker・検索（実通信）

`.github/scripts/verify-magi-publication.mjs --phase worker`と`test-site-search-ui.mjs --base https://tk.st --live`をGitHub ActionsのChromiumで実行した。結果はrunの`magi-publication-worker` artifactに保存した。

- SSE：最初のコメント2,048バイトが0.682秒で到着。10.659 / 20.661 / 30.662秒にpingが届き、33.174秒で`done`。99塊、`integrated`148件、`error`なし。`Cache-Control: no-cache, no-transform`を確認した。curlの代わりにNodeのストリーム読み取りで同じ実API・Originを使い、各受信の時刻を記録した。
- 新入口のsite / tools / game / nitori / retail：5scopeすべて`results`・`complete:true`。画面が送ったgenerationと応答のgenerationが一致した。②は実Jevで、固定応答へ差し替えていない。
- 旧入口のsite / nitori / retail：200、結果あり、完了。tools / game：400 `invalid_request`で、③へ流れない。
- トップSearch：DJを検索し①と②を表示。コマンドの実行では②のPOSTを追加しない。
- 404の③：PDFで200・結果1件。説明にOpenAI・DeepSeek・Googleがある。
- URL・参照元・計測：本物のGTM・Ahrefsを読み、送信を記録して停止。5scopeの検索語の漏れ検査、日刊の明示的な受け渡し、JavaScript無効時のリンクを確認した。インフラ側の参照元の例外12件は既存検査の区別を維持した。OSのIME・読み上げの実機検査ではない。

手元Windowsからの最初の5scope検査はgameで既存の日次上限`rate_limited`になった。制限・DB・IPを変更せず、CIの通常の公開検査で5scopeが成功した。これはWindowsからの全件成功として数えない。

初回CIは`X-Accel-Buffering: no`の外側の応答への出現を要求して止まった。[Cloudflareはこのヘッダーを訪問者向け応答から除去する](https://developers.cloudflare.com/fundamentals/reference/http-headers/#removed-response-headers)。Workerの指定は単体検査で確認し、本番では省略または`no`を許容する検査へ修正した。製品コードは変更していない。失敗した[38250670893](https://github.com/tk33r1/st/actions/runs/38250670893)も記録として残した。

## 本番画面と公開資産

`.github/scripts/verify-magi-publication.mjs --phase pages`をChromiumで実行した。トップはデスクトップ幅、PWAとDJは390px幅。トップ・PWAの4.5表示を確認してから合成相談を送り、3画面すべて`done`までの通常受信、注記なし、本文表示、履歴への本文の完全一致の保存、入力欄の完了、画面例外なしを確認した。保存した本文はトップ96文字・PWA103文字・DJ94文字。DJの本番受付は開いており、画面から実際に相談を送った。受付設定や曲リクエストは変更していない。結果はrunの`magi-publication-pages` artifactに保存した。

初回[38251618444](https://github.com/tk33r1/st/actions/runs/38251618444)ではトップ・PWAが成功し、DJは検査器が受付中に起動時には読まない`/board`を待って30秒で止まった。実際の受付判定`/event`を待つよう修正し、3画面を再検査して成功した。製品コードは変更していない。

公開物と画面コミットの照合では、トップ/DJの製品インラインJS、PWAの製品HTML・`app.js?v=20261012_1`・`sw.js`が一致した。HTML全体にはCloudflareが解析・検査スクリプトを追加し、トップのJSON-LD更新日はsitemap botが同期するため、それらと製品JSの照合を分けた。PWAの`app.js`はSHA-256 `bdeedb7f8f8c63b2ec4ce2a466ec6b8af79ab8ab7682cf95f3b2a7c3af96a15f`、`sw.js`は`863b9a4fc047a0d943d99c8d2040e69b49e7e3721687f0196a1cd5a5e257e63d`。

`verify-phase4-release.mjs`で、本番の共通検索JS/CSS6ファイルの生バイト列がGit正本と一致した。読み索引を照合し、5scopeの全タイトルを検索できた（site 96 / tools 9 / game 8 / nitori 197 / retail 214件）。深いパスの404と共通資産の版も成功した。AIの精度を測り直した記録ではない。
