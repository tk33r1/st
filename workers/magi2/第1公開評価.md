## Cloudflare経路の404検索

専用Worker・専用D1・Accessサービス認証・専用APIキーで、本番DBを使わずに計測した。全体上限20・IP上限10は維持し、評価用DBの検索カウンターだけを10件のバッチ間で初期化した。通常利用との競合を抑えるため開始間隔30秒以上。

| 項目 | 結果 |
| --- | --- |
| 入力 | 日本語10件・英語10件を2回、計40検索 |
| 関連リンク | 正解を事前に定めた候補あり36件で36/36。全リンクは公開索引のID・URLと一致 |
| 候補なし | 航空券の予約に関する4件。全て予約できないと案内。3件は候補なし、1件は実在のContactへの任意の案内。予約機能・制作の約束なし |
| 待ち時間 | 中央値5,912ms・P90 7,414ms・最大20,286ms。時間切れ0/40 |
| API | 各検索8回。OpenAI160回・DeepSeek80回・Google80回、すべてHTTP 200でusageを取得。再試行なし |
| 通信の打切り | AIを使わない専用筋書きで149秒のJSONが149,221ms・HTTP 200、151秒の筋書きは150,032ms・HTTP 503。途中切断なし |

検索の説明を公開索引と照合し、存在しないリンク・未確認の機能・制作の約束は見つからなかった。最終コードで追加した匿名の利用量記録と人格本文の保険は以下の追加評価・単体検証で確認した。上の40件では人格本文は4000字未満で、保険による切り詰めは発生しない。

最終コードでAPNG→MP4という未提供・逆方向の用途を日英で追加確認し、両方とも候補なし、未提供機能を案内しなかった。匿名カウンターは評価用DBでchat/404別に記録され、HTTP 429の記録とDB失敗で回答を止めない扱いは単体検証で成功した。
評価終了後に専用Worker・D1・DNS・Accessアプリ・作成した専用サービス認証を削除した。利用者が保存したCloudflare APIトークンと元からあるサービス認証には触れていない。

## 費用

2026-10-05に[OpenAIモデル料金](https://developers.openai.com/api/docs/models/gpt-6-luna)・[DeepSeek料金](https://api-docs.deepseek.com/quick_start/pricing/)を確認。モデルIDは `config/ai-models.json` に従う。以下はAPI費用のみ、USD。D1・Worker等の費用は含めない。

| 会社 | 100万tokenあたり入力／出力 |
| --- | --- |
| OpenAI | 非キャッシュ0.10、キャッシュ読取0.01、書込0.125／出力0.50 |
| DeepSeek | ピーク時は非キャッシュ0.30、読取0.006／出力1.20。オフピークは半額 |
| Google | 利用者の無料枠。費用0、割当量は別途制約 |

usageを上の単価へ換算すると40件合計$0.037128、平均$0.000928・最大$0.001607。DeepSeekは高い方のピーク単価を当てた保守的な換算で、請求額そのものではない。

想定最大は、UTF-8の1byteを入力1token、さらにメッセージごと256tokenの余裕を置き、キャッシュ割引なし・DeepSeekピーク単価で計算した。候補16000字と固定指示・JSON・問いの4000byteの余裕から、選択は52000入力token。3件の題名160字・説明320字、カード各2000字、検索語200字、人格本文は保険の4000字を上限に、実際の共通関数が組む入力を計測した。各人格2回の全呼出しを2試行とし、統合1回・選択1回で計14試行。出力も設定の上限（人格512/1024/512・統合4096・選択120）を使う。

新版は1検索$0.077321×20=$1.546414/日。旧版は同じ候補・入力の余裕と出力300tokenで1検索$0.006650×300=$1.995000/日。新版は旧予算内。これは上限に基づく計画用の見積もりであり、単価変更後の保証ではない。

## 無料枠の運用

確認時のGoogle割当量は15 RPM・250,000 TPM・500 RPD。通常チャット300質問と404検索20回が同日に全て成功する保証はしない。利用者の2026-10-05の選択に従い、無料枠を維持して実利用量・HTTP 429で管理する。
Workerのchat/404別の匿名日次カウンターとAI Studioの全体使用量を併用する。競合時は404全体上限を下げ、0で404のAI検索だけ止める。通常チャットの上限300は維持する。本文・利用者IPをこの集計には含めない。
