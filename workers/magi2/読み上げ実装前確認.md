## §0.6 WebSocket の測定

- `workers/magi2/probe.js` に設計§6.5 の一時の測定を実装し、`src/index.js` の入口の先頭につないだ。`wrangler.toml` の `PROBE_ENABLED="true"` のときだけ動く。AI・D1・secret を使わない。
  - `GET /magi2/probe`: 測定のページ（noindex）。［開始］で SSE と WebSocket を同時に 60秒受け、開けたか・件数・最初の受信・間隔の最大・遅れの最大・最後まで届いたかと、判定を表示する。結果はどこにも送らない。
  - `GET /magi2/probe/sse`・`/magi2/probe/ws`: 2秒ごとに番号と Worker の時刻を送る。SSE はチャットと同じ 2KiB の最初の合図と見出しを付ける。測定のページの Origin（`https://workers.tk.st`、手元は loopback）か Referer の GET だけを受け、isolate ごとに同時6本まで。
- `test-magi2.mjs` に、無効なら 404、ページ・Origin と Referer の検査・`Upgrade` の無い WebSocket の 426・SSE の最初の合図、AI を呼ばないことのテストを足した。全 304 件が成功。`wrangler deploy --dry-run` も成功。
- 手元の `wrangler dev` と Chromium で、測定のページを2通りで開いた（それぞれ 60秒）。

| 経路 | SSE | WebSocket | 判定の表示 |
| --- | --- | --- | --- |
| 直結 | 30件、最初 2.1秒、間隔の最大 2.0秒 | 30件、間隔の最大 2.0秒 | SSE は少しずつ届いている（WebSocket は不要） |
| SSE だけ溜め、WebSocket は素通しにする手元の中継 | 30件、最初 60.1秒（全部まとめて） | 30件、間隔の最大 2.0秒 | WebSocket に効果あり |

- **本番へのデプロイ**（2026-10-23、本人の承認後。コミット 871e9372 の上、Version ID `3934d4fa-4c42-441a-803b-15415281d1dd`）: 公開中の 5.9 との違いは測定の入口だけ（main との間の Worker・カードの差分は無し）。
