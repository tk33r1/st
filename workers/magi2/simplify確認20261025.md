# magi2のsimplify確認（2026-10-25）

実装済み（2026-10-25）。正本はコード。本人の「修正して」により、確認時に挙げた4点を整理した。着手時に存在した未コミットの変更を保持し、その時点の作業ツリーを変更前の基準にした。

## 変更

1. `runDiscussion`の人格設定・統合に渡す討議本文・統合メッセージ列を、`discussionPersonas`・`discussionSynthesisText`・`discussionSynthesisMessages`へ切り出した。並列呼び出し、欠席、判定、採決、ページ選択待ち、期限、イベント送信は本体に残した。
2. POSTの7入口を`POST_ROUTES`へまとめた。検索のno-storeと認可ログ、リアクションの認可文言、読み上げ停止時の404を保持した。GET・WebSocketの入口は従来のまま。
3. 出典とアイコンに共通する相対URLの解決・公開URLの検査を`researchSourceTarget`へまとめた。リダイレクト上限、取得する種類、読み取り量、失敗後の扱いは各取得処理に残した。
4. 出典本文の取得・HTML抽出・アイコン処理を、`src/index.js`から既存の`research.js`へ移した。AI呼び出し・照合・Browser Runの制御は入口側に残し、循環依存を作っていない。部分読み込みを使う`magi-search-config.mjs`と`magi-a2-verification.mjs`を追従させた。過去の有料評価スクリプトは書き換えていない。

プロンプト、モデル、上限、再試行条件、旧契約、SSE/WebSocket、一時会話の契約、画面、版番号は変更していない。`src/index.js`は着手時から211行減った。ファイル分離と関数抽出が中心なので、全体の行数削減を目的にはしていない。
