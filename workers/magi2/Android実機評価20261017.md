# Android実機評価（2026-10-17）

本人がUSB接続したSamsung SM-S931Q、Android 16、WebView 155.0.8059.43で実施。開始時はMAGI **4.6/46**、終了時は正式配布の **5.1/51**。通常の上書きインストールを行い、アプリデータの消去・私的な会話の送信は行っていない。端末シリアルは記載しない。

## 確認できたこと

| 項目 | 実機での結果 |
| --- | --- |

| 通知を閉じた版 | 閉じたあと、4.6を終了・再起動しても5.1の通知を再表示しない |

| 会話履歴の引き継ぎ | 更新前・更新後・全操作後で5件。各タイトルのhashと並びも一致。会話本文の全バイトを比較したという意味ではない |

APK SHA-256: `951b18ffb0f4173c78bdeb36437dfd324e4d7dc461e2785096ad6905a9f4c9d0`。旧版と5.1の署名証明書SHA-256: `0ab1a655a53a2b39d325167508a9b37d2ded1e9d1e6ae4a00431d28b54a41df9`。

機内モードの最初の試行は切断直後の確認が早すぎたため、質問を送信する前に安全側で停止して設定を復元した。切断完了を最大5秒確認するようにし、再実施は既定ネットワークなしを確認して成功した。失敗した試行も記録を保持。

## 未確認の条件

- 通常相談・MAGI・画像付きの各1回を、実機から本番AIへ送り、最後まで回答させる確認。今回の送信は通信経路のない状態の合成質問だけで、**実機からの有料AI呼出しは0**。
- 聞き返し選択肢や悪意での終了を、実モデルの生成から実機操作まで通す全件確認。
- 24時間の実経過による更新照会の抑止。閉じた版の再起動後の抑止とは分ける。
- Androidの単色アイコン、iPhone/Safariの実機。
- 機内モード時の更新履歴は既存HTTPキャッシュが表示された。更新履歴の取得失敗文言を実機で再現したとは数えない。

既存の累計上限維持の指示に従い、これらを無料の画面操作の合格へ読み替えない。Bの新しいネイティブ機能やFish Audioの実装も行っていない。
