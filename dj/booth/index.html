      このページの BPM とキーは GetSongBPM から提供を受けています。GetSongBPM は楽曲の BPM・キー・拍子といったデータを 無料で公開している音楽データベースで、API を通して誰でも利用できます。
      そこで取れなかった値は、このブラウザが30秒プレビューを解析して推定しています（点線の「推定」）。 音声はどこにも送りません。プレビューは曲の一部なので、キーは平行調（Am と C など）を取り違えることがあります。
      曲の背景は、OpenAI に Web 検索をさせて作っています。送るのは曲名・アーティスト名などの曲の情報だけで、 リクエストした人の名前やひとことは送りません。出典を確かめられた事実だけを出し、出典の無い繋ぎの助言は「AI の見立て」と書いています。
