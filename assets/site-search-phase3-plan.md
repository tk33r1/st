# サイト内検索 Phase 3 実装計画書

草案（2026-10-09）。資料作成に着手済み。機能の実装・実API評価・公開は未着手。

要件は [PRD](site-search-phase3-prd.md)、作り方は [設計書](site-search-phase3-design.md)、合否は [検証計画書](site-search-phase3-verification.md)。本書は作業の順番・依存・完了条件と進み具合だけを管理する。Phase 0〜2の既存T番号と区別するため `P3-Txx` を使う。T06・T07・T12は、共通契約とtools/gameを扱う `-C`、日刊の追加を扱う `-D` に分ける。

## 1. 進め方

- 作業はCodexが進め、仕様の確認・公開判断は本人が行う。実APIの精度測定は評価セットを固定し、費用と共有上限の見積もりを提示してから実行する。
- 設計のレビューでPRDの追加案を確定し、コードと検証の期待値をそろえる。既存のPhase 2の合格記録をPhase 3の合格記録として流用しない。
- 1作業1コミットを基本にする。サイトへ出る変更は公開単位が完成してからmainへ入れ、pushは本人の指示に従う。
- 現在の作業ツリーには検索の整理と別件の変更がある。実装開始前に基点・対象差分を整理し、別件を公開単位へ混ぜない。
- 日刊botの最新号を取り込んだ後に再生成する。再生成の直後にbotの号が増えた場合は取り直す。共通JSの参照更新と対応HTMLは同じpushで出す。

## 3. 公開単位と順序

| 単位 | 含めるもの | 公開時点の状態 |
| --- | --- | --- |
| A1 tools/gameの索引準備 | category_key | 旧画面が動き、新scopeは停止したまま |
| B1 共通Workerとtools/gameの準備 | 共通契約・tools/game・③・停止・回数・ログ | 許可scopeはsiteだけ。日刊は未実装でも停止可能。本番評価時だけ対象scopeを開ける |
| C 共通③の移行 | site-search.js・404・参照版番号 | siteだけを使う404の回帰を先に確認 |
| D tools/game | 各一覧UI・CSP・説明・head・計測、対象scopeのAGENTS/JEV/README更新 | A1/B1/Cと対象scopeの評価が完了。game一覧のClarity除外またはGTM停止を確認して公開 |
| A2 日刊の索引準備 | generation、全年度索引 | 旧UIと互換。A1/B1/C/Dの前提にしない |
| B2 日刊Workerの追加 | snapshot・候補・日刊②③ | 対象媒体を停止したまま追加し、B1の公開scopeを維持 |
| E 日刊 | daily-ui.js、テンプレート、全号のJS参照、ポータル、対象媒体の運用文書更新 | A2/B2/Cと対象媒体の評価が完了。両誌共通JSは互換のまま、媒体ごとに公開 |

出荷ファイルを変えるD/Eは別々の公開単位とし、同じ作業ブランチへ未完成の両方を載せない。bot・他の改修と重なる場合は差分を比較し、生成物を一括で上書きしない。T04の索引追加だけで号の本文やdateModifiedを変えない。T11の参照更新の再生成は既存の `Date-Sync: skip` の扱いを確認する。

表のA2/B2は日刊の追加工程で、tools/game公開前の必須工程ではない。DとEの各scopeは必要な前提だけを確認して公開する。公開後は対象scopeの停止専用コード・一時障害・再読み込みによる再開を確認する。

## 4. 検証と実行上の注意

手元の単体・UI検証は模擬上流で行う。既存 `test-magi2.mjs`、`test-site-search-index.py`、`test-daily-news.py`、`test-site-search-ui.mjs` を再利用し、Phase 3の抜けを追加する。実APIを呼ぶCLIはscope・回数・対象索引を明示できるようにする。

本番の③は全体20回/UTC日を全画面で共有している。精度の大量測定を本番の③へ流さない。既存 `env.eval` のDB・Access設定を先に確認し、評価専用の設定へ出す。通常のdeploy-worker workflowへ評価環境を追加しない。

実測は新しいモデル・契約・単価を推測せず、設定と公式資料を直前に確認する。キー・検索語を含む生の記録は `workers/.wrangler/` の追跡外だけ。合格記録はscope単位で [検証計画書](site-search-phase3-verification.md) にリンクする。
